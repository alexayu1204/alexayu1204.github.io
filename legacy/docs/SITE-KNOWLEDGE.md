### Surfaces, elevation, theming reality
- **Warm-paper bg** (`#faf7f3`) makes pure-white cards float; `--elev-1` resting / `--elev-2` on hover; `.info-card` gets `1px solid var(--hairline)` borders.
- **Theming mechanism:** a `data-theme` attribute on **`document.body`** (not `<html>` — audit wanted `<html>`, unfulfilled). Light = default `:root`; dark = attribute selector re-declaring the same custom-property names.
- **The `!important` / dark-mode reality:** ~**59 `!important` declarations**, almost all confined to `[data-theme="dark"]` Bootstrap overrides. Bootstrap doesn't read these custom names, so a dedicated block remaps Bootstrap's own `--bs-*` variables (`--bs-body-bg`, `--bs-card-bg`, all `--bs-accordion-*`, `--bs-border-color`) and a long series of explicit overrides force Bootstrap's hard-coded white surfaces (`.card`, `.modal-content`, `.bg-white`, `.bg-light`, accordion internals, list-group, dropdown, popover) onto the dark card color. Acknowledged **pre-existing debt**; the "proper" fix is a risky `data-bs-theme` migration explicitly advised against for a working site.
- **Redundancy notes:** dark-mode accordion rules declared twice (Table-Styles block + "Simple Solution" block, later wins); `.text-muted` dark color set twice (`var(--secondary-color)` then hard-coded `#9e9e9e !important` wins); a few hard-coded hex literals (`#2c2c2c`, `#252525`) bypass tokens.

## 5. JavaScript behaviors

**Global:** `PREFERS_REDUCED_MOTION` — evaluated **once at parse time** (matchMedia-guarded), consumed only in AOS `disable:` and the filter scrollTo behavior. Not re-evaluated live (unlike dark mode, which IS followed live).

**`DOMContentLoaded` init order (fixed):**
1. **AOS init + CDN-failure reveal** — `AOS.init({duration:700, easing:'ease-in-out', once:true, offset:80, disable:PREFERS_REDUCED_MOTION})` in try/catch; if AOS missing/threw, force every `[data-aos]` to `opacity:1; transform:none` (fail-open against AOS's `opacity:0` CSS).
2. **Bootstrap tooltips** — `new bootstrap.Tooltip(el)` per `[data-bs-toggle="tooltip"]`. **NOT guarded by `typeof bootstrap`** — the one hard, unguarded dependency; would abort the rest of the handler if Bootstrap's CDN failed.
3. `initBackToTopButton()` — rAF-throttled, toggles `.is-visible` past 300px; click = smooth scroll-to-top (ignores reduced-motion).
4. `setupNavbarBehavior()` — mobile collapse hide gated on `.show` class (the desktop-flicker fix — avoids instantiating Collapse on `navbar-expand-lg` desktop).
5. `setupDarkModeToggle()` — richest function: `setThemeColorMeta(isDark)` (`#121212`/`#faf7f3`), `applyTheme(theme, persist)` (sets `data-theme` on body, swaps sun/moon icon, persists to localStorage), keyboard handler (Enter/Space/Spacebar), and **live OS-theme following** only when no explicit localStorage choice (skill-pill colors handled entirely by CSS — no inline-style bookkeeping).
6. `setupProjectCarousel()` — `updateArrows()` rAF-throttled (disables arrows at extremes with 1px tolerance, toggles `at-start`/`at-end` for edge-fades); listens for `scroll`, `resize`, and a `cards:filtered` event; ArrowLeft/Right keyboard nav; `scrollCarousel()` pages by `cardWidth+16` (respects `.is-hidden` filter); `setupCarouselTouchSupport()` (50px swipe threshold, no vertical-dominance guard).
7. `setupPreviewModal()` — on `show.bs.modal`, reads `data-url`/`data-title`/`data-offset` from the trigger; **3-way branch**: `.md` → `fetch`+`marked.parse` into injected `.markdown-body.markdown-preview`; `wixsite.com` → `.preview-fallback` "Open in new tab" card (graceful X-Frame degradation); else generic iframe (cross-origin scroll in try/catch). Clears body on `hidden.bs.modal`.
8. **Enhancement layer:** `initScrollProgress()` (rAF width %), `initScrollSpy()`, `initPortfolioFilter()`, `initCopyButtons()`.
9. **orientationchange** → 300ms `setTimeout` → guarded `AOS.refresh()`.

**`initScrollSpy()`** — tracks **every** `main > section[id]` (incl. the unlinked hero), resolving nav links via `linkForSection()` (links point at `*-header` anchors *inside* sections, so it resolves the anchor then walks up to its `<section>`). Sets `.active` + `aria-current="page"` honestly (an unlinked current section leaves no stale active link). Bottom-snap within 4px walks back to the last linked section. Its comment still names removed sections ("stats, Online Profiles, Resume") — **stale comment, harmless** (code is generic; only `#header` hero is genuinely unlinked now).

**`initPortfolioFilter()`** — delegated click on `#portfolioFilters`; `data-filter` tokens vs card `data-tags` (`tokens.some(...)`); toggles `.is-hidden`; sets `aria-pressed`; resets scroll honoring reduced-motion. **Bug:** never dispatches the `cards:filtered` CustomEvent the carousel listens for (§9).

**`initCopyButtons()`** — Clipboard API with `execCommand` fallback + 1800ms toast + icon swap to check (1500ms); `onCopied` fires even on the synchronous fallback path.

**Engineering patterns:** rAF coalescing ×4 (each with local `ticking` + `{passive:true}`); defensive null-element early returns everywhere; try/catch around AOS.init, clipboard fallback, cross-origin iframe scroll (3 intentional silent catches); a11y (keyboard toggle, `aria-current` spy, `aria-pressed` chips, carousel arrow-key region).
